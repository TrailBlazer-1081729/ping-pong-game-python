\# Ping Pong Game



A classic Ping Pong game built using Python and Turtle graphics.



\## Features

\- Two-player gameplay

\- Ball collision mechanics

\- Paddle controls

\- Score tracking

\- Increasing game speed



\## Tech Stack

\- Python

\- Turtle Graphics



\## How to Run



```bash

python main.py

```



\## Controls



| Player | Keys |

|---|---|

| Left Paddle | W / S |

| Right Paddle | Up / Down |
